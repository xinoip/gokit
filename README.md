# Pio's Go Kit

This is a library project that is in no way intended to be consumed as a
traditional Go library. It contains common utilities and patterns that I have
encountered and have a need for across different Go projects.

Intended way of using these are simply copying it into the project. I try to
keep each sub-package isolated. So each of them can be copied into a new project
and used as a library.

Check out sub-packages for their own documentation. Examples are provided in the
form of testable examples supporting `godoc`.
